# login-app

Expo Router로 만든 간단한 로그인/회원가입 앱입니다.

## 주요 기능

- 이메일 형식 검사
- 비밀번호 8자 이상 검사
- 회원가입 비밀번호 확인 검사
- 비밀번호 보기/숨기기
- 로그인 화면과 회원가입 화면 이동

## 실행 방법

프로젝트 폴더로 이동합니다.

```bash
cd ~/Developer/login-app
```

앱을 실행합니다.

```bash
npx expo start
```

웹에서 바로 확인하려면 아래 명령어를 사용할 수 있습니다.

```bash
npx expo start --web
```

## 확인 방법

1. 로그인 화면에서 이메일을 비워두거나 잘못된 형식으로 입력하면 오류 메시지가 나오는지 확인합니다.
2. 비밀번호를 비워두거나 8자 미만으로 입력하면 오류 메시지가 나오는지 확인합니다.
3. `회원가입`을 눌러 회원가입 화면으로 이동하는지 확인합니다.
4. 회원가입에서 비밀번호와 비밀번호 확인이 다르면 오류 메시지가 나오는지 확인합니다.
5. 올바른 값을 입력하면 완료 알림이 나오는지 확인합니다.

## 코드 검사

문법과 기본 규칙을 확인합니다.

```bash
npm run lint
```
